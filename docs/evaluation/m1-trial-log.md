## 2026-10-18 阿里云百炼 AI试衣（aitryon-plus / aitryon）：用不了

**结果：❌ 当前账号调用不到 AI试衣模型。**

| 尝试 | 结果 |
|---|---|
| 脚本先上传图片到百炼临时存储（getPolicy） | `HTTP 404 InvalidParameter: Model not exist.` |
| 跳过上传，直接用公网图片链接下单 | 同样是 `Model not exist.` |
| 旧地址 `dashscope.aliyuncs.com` × {aitryon-plus, aitryon} | 都是 `Model not exist.` |
| 业务空间专属地址 × {aitryon-plus, aitryon} | 都是 `Model not exist.` |

- API Key 本身是有效的：返回的是 404（找不到模型），不是 401（认证失败）。
- 控制台的模型广场里也搜不到 `aitryon-plus`。
- 控制台左下角提示"部分功能使用受限"，**可能和实名认证有关**，还没核实。
- 计费文档里仍然列着 AI试衣的几个模型，没有找到下线通知。

**待办：** 问百炼客服"新账号能否开通 aitryon-plus"，附上本次的 request_id。

**顺带解决的问题：** 第一次运行时报 `SSL: CERTIFICATE_VERIFY_FAILED`，原因是 python.org 安装的 Python 3.14 缺少证书。运行 `/Applications/Python 3.14/Install Certificates.command` 后解决。

## 目前的发现

1. **国内候选要换**：AI试衣 Plus 暂时用不了，但同一个账号里的 Qwen-Image 能用，而且"像实拍"这一项表现很好。
2. **通用改图模型的短板是文字**：图案和颜色基本没问题，但英文字会乱码。买家最在意"字和 Logo 对不对"，所以这是一个关键问题。
3. **截图要先裁干净**：页码、黑边这类界面元素会被 AI 当成照片的一部分。以后 DrapeLoop 上传衣服图时，应该让用户先框选衣服区域。
4. **"保持姿势不变"不一定会被遵守**，正式评测时要把姿势变化记进 B / E 项。
5. **专门的试衣模型（FASHN）在文字和 Logo 上明显强于通用改图模型（Qwen-Image）**；两者都很像实拍。FASHN 的新问题是**宽松版型可能被"穿"成合身款**，正式评测要专门放几件宽松款。
6. **可灵 Kling Image 3.0 在三家里最均衡**：文字几乎全对（只有 ® 变形），颜色和宽松版型都比 FASHN 准；短板是网点细节和轻微的锐化感。它是通用改图模型，可灵专门的 Kolors 试衣模型可能还会更好。
