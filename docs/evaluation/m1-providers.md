# M1 试衣服务候选 / M1 Try-On Provider Shortlist

更新：2026-10-18｜对应 issue：#6｜状态：初选，等实际注册和小规模试用后确认

> **2026-10-18 更新：** 实测发现当前账号调用不到阿里云 AI试衣（`Model not exist`），同一账号里的通用改图模型 Qwen-Image-3.0-Pro 可以用，"像实拍"表现好，但文字会乱码。详见 [m1-trial-log.md](m1-trial-log.md)。下面的推荐会等 FASHN 试跑完再更新。

> 价格和条款都来自 2026 年 10 月能查到的公开页面，有些是第三方转述。**付费前一定以官网和控制台为准。**

## 一、挑选标准

| 标准 | 为什么重要 |
|---|---|
| 能不能做到像实拍 | DrapeLoop 的核心要求，"一眼 AI"就算不能用 |
| 商品图要求 | 中国买家拿到的多半是**模特上身图或截图**，不是干净的平铺图 |
| 国内能不能用 | 目标用户在国内 |
| 照片怎么处理 | 会不会保存、多久删除、会不会拿去训练 |
| 怎么收费 | 单价、免费额度、最低充值 |
| 有没有接口 | 要能接进 DrapeLoop 的后端 |
| 能不能出多角度 | 为路线第 ② 步做准备，加分项，不是必须 |

## 三、推荐：阿里云 AI试衣 Plus + FASHN

**1. 阿里云百炼 AI试衣 Plus**
- 国内服务，人民币付款，以后真给国内用户用也最省事。
- 400 张免费额度，M1 测试基本不花钱。
- 弱点：要求平拍图。可以顺便测一下"模特图 → 先分割出衣服 → 再试穿"这条路，或者直接看它拿到截图时效果有多差。

**2. FASHN**
- 模特上身图也能直接用，最贴近中国买家"随手截图"的习惯。
- 隐私条款写得最清楚：结果 3 天后删除，默认不拿去训练。
- 弱点：海外服务。M1 拿已经同意的测试照片来试没问题，但以后给国内真实用户用时，个人照片要传到境外，需要另外评估是否合规。

**可灵当备选**：如果前两家有一家注册不了、或者付不了款，就换成可灵。

**淘宝 AI试穿当对照组**：用同样的照片手动试一遍。推荐的两家里，至少要有一家比淘宝更像实拍，DrapeLoop 才有做下去的意义。

## 四、开始测试前还要确认

- [ ] 两家都能注册，也能付款（FASHN 要试试国内能不能付）。
- [ ] 阿里云 AI试衣的照片保存和训练条款。
- [ ] 各自的结果链接多久过期（M1 要及时把结果图下载到自己电脑上）。
- [ ] 各用 1～2 张照片先小试一下，确认能跑通，再跑完整的 12 组。
