## 可灵 Kling Image 3.0（网页版，2026-10-20）

- 12 组全部用固定提示词，每组只生成一次，参数 2K · 自适应 · 1 张。
- 每张扣 1 灵感值，共 12 个（免费额度）。免费账号要排队，第一组约 45 秒，后面几组排队 1～5 分钟。
- 结果图带 "AI生成" 和 "可灵AI 3.0" 水印。

### 结果：12 组里 6 组能用，没有达到 9/12 的门槛

| 组 | 结论 | 主要问题 |
|---|---|---|
| S01 | ❌ | 英文字变成乱码（试跑时文字是对的，这次人在画面里更小，字也更小） |
| S02 | ✅ | 大码没有被 P 瘦 |
| S03 | ❌ | 色差明显：藏青条纹衬衫变成偏亮的牛仔蓝；条纹变细 |
| S04 | ✅ | 促销横幅和中文卖点没有带进来；直角肩没了 |
| S05 | ❌ | 版型差太多：落肩宽松的圆领开衫变成合身的立领拉链款 |
| S06 | ✅ | 模特的挂绳小包被带了过来 |
| S07 | ✅ | 人像印花变粗糙 |
| S08 | ❌ | 衬衫本身还原得很好，但牛仔裤和姿势被换成模特的 |
| S09 | ✅ | 人像印花还原得较好 |
| S10 | ✅ | 花体字基本对；图案变形；带入手表和手镯 |
| S11 | ❌ | 裙子被换成模特的迷彩裤和靴子；带入项链 |
| S12 | ❌ | 长袖变短袖 |

### 主要发现

1. **"像实拍"和"像本人"都很好**：12 组的脸、表情、背景几乎都保持住了，没有一组被 P 瘦。
2. **模特图会"串货"**：衣服图里模特的裤子、鞋、项链、手表、挂绳会被一起带过来（S06、S08、S10、S11）。提示词明确说了"不要带过来"也没用。淘宝很多商品只有模特图，这是最大的问题。
3. **色差和关键款式会走样**：S03 藏青变牛仔蓝；领型（S05）、袖长（S12）、直角肩（S04）。
4. **小字容易乱码**：同一件 T 恤，人在画面里越小，字越容易错（S01 对比试跑）。
5. **截图上的界面元素这次都处理得很好**：促销横幅、"穿上试试"按钮、品牌名都没有带入。

### 打分时多用的两条判断（已写进打分标准）

按当时的规则逐条对照后，还有两种情况判了"不能用"，因为买家看到会被误导：
- **下装或姿势被换成衣服图里模特的**（S08、S11）；
- **袖长、领型这类关键款式错了**（S05、S12）。

这两条已在 FASHN 评测前写进 [m1-scoring.md](m1-scoring.md)（见"修改记录"），两家都按这一版判。只带入小配饰（S06 的挂绳包、S10 的手表手镯）仍然只扣 D 分，所以可灵的结果不用改。

### 补充小实验：先把衣服图裁到只剩上衣（2026-10-20）

> 单独记录，**不改正式结果**（正式结果还是每组跑一次、6/12）。

**想验证什么**：S08、S11 不能用，主要是衣服图里模特的裤子、姿势、项链被带了过来。如果先把衣服图处理成"只有上衣"，还会不会串货？

**怎么做**：
- 人物照不变；衣服图在本地手工处理成新文件（原图不动）：
  - S08 条纹衬衫：去掉品牌名和模特的脸，衬衫敞口里露出的裤子涂成白色。模特压在左肩上的长发去不干净，保留了。
  - S11 粉色印花 T 恤：只保留 T 恤，去掉脸、项链、手、手表、手镯、裤子和地板。领口下面留了一个小修补痕迹。
- 可灵设置、提示词和正式评测完全一样，每组只跑一次。共扣 2 灵感值。

**结果**：

| 组 | 正式评测（原图） | 裁剪后 | 变化 |
|---|---|---|---|
| S08 | ❌ 牛仔裤和姿势被换成模特的 | ✅ 自己的牛仔裤、皮带、插兜姿势都保住了；衬衫敞开叠穿、条纹、扣领都对，没有 P 瘦 | 串货消失，变成能用 |
| S11 | ❌ 裙子变成模特的迷彩裤和靴子；带入项链；花体字变形 | ❌ 自己的格子裙、凉鞋、姿势都保住了，也没带入模特的项链（保留的是她自己原本的细项链）；但花体英文字还是乱码，印花变简单 | 串货消失，但文字问题还在，仍不能用 |

参考打分（不进打分表）：S08 裁剪版 A5 B5 C4 D4 E4 F4；S11 裁剪版 A5 B5 C4 D2 E4 F4。

**结论**：
1. **"串货"基本是衣服图里有别的东西造成的**，先把衣服单独抠出来就能解决：两组的下装、鞋、姿势、项链都没再被带过来。
2. **裁剪解决不了文字乱码**：S11 的花体字照样错，这是模型本身的问题。
3. **可灵会照搬衣服图上的瑕疵**：S11 领口下的修补痕迹在结果里变成了一个小黑点。所以如果要做自动抠图，抠出来的图要干净。
4. 如果正式评测里 S08 也用裁剪图，可灵会是 7/12，仍然没过 9/12。

**对产品的启发**：在 MVP 里加一步"自动把商品图里的上衣抠出来"值得考虑，用户上传的截图大多是模特图。这一步要用现成的抠图/分割工具自动完成，本次是手工做的，样本只有 2 组，只能当作方向参考。

## FASHN（网页版 Agent，2026-10-20）

- 免费账号有 8 个额度，每生成一张扣 1 个，所以先跑优先的 8 组：S01、S02、S03、S04、S05、S07、S10、S11。剩下 S06、S08、S09、S12 要等是否充值 API 再决定。
- 每组新开一个 Agent 对话，先传人物照、再传衣服图，用固定提示词的英文版（见 [m1-test-set.md](m1-test-set.md)），每组只生成一次。设置里的比例、分辨率、生成模式都保持 Auto。
- Agent 每次都调用名为 "Generate Image" 的工具，生成 1 张，约 50～70 秒，不用排队。结果 1600×2400 左右，没有水印，下载时选 "Original" 格式。
- 衣服图都用原图（没有用裁剪版），和可灵一样。

### 结果：跑了的 8 组全部能用

| 组 | 可灵 | FASHN | FASHN 的情况 |
|---|---|---|---|
| S01 | ❌ | ✅ | 两行英文字逐字正确，® 和袖标都在；截图的页码、黑边、品牌名没带入 |
| S02 | ✅ | ✅ | 没有被 P 瘦；姿势、皮带、手表、牛仔裤都保持 |
| S03 | ❌ | ✅ | 藏青条纹颜色准（可灵变成了牛仔蓝）；扣领、口袋、宽松落肩、敞开叠穿都对 |
| S04 | ✅ | ✅ | 促销横幅和中文卖点没带入；直角肩没还原（和可灵一样） |
| S05 | ❌ | ✅ | 圆领纽扣开衫款式对（可灵变成了立领拉链款）；没带入模特的项链 |
| S07 | ✅ | ✅ | 人像印花比可灵细致；颜色稍微偏红 |
| S10 | ✅ | ✅* | 花体字正确；没带入项链手表；**外面保留了人物原来的白色开衫** |
| S11 | ❌ | ✅* | 花体字正确，水洗粉颜色和做旧质感好；没带入模特的迷彩裤和项链；**同样保留了白色开衫** |

**同样这 8 组：可灵 4/8，FASHN 8/8。**

\* S10、S11 的人物原来穿的是"白色开衫 + 抹胸"。FASHN 只把里面的抹胸换成了 T 恤，开衫还在外面，所以 T 恤的短袖和宽松版型看不到，T 恤看起来也偏短。按现行规则这不算"款式错"，也不算"串货"，所以判了能用，但 E 项只给 3 分，买家问题记"不确定"。复核后维持"能用"：衣服本身（颜色、图案、文字）都对，人物自己的衣服也没被乱改，开衫的问题放到产品规则里解决（见下一步建议第 3 条）。

### 两家对比

| | 可灵 Kling Image 3.0 | FASHN |
|---|---|---|
| 像本人、没 P 瘦、像实拍 | 好 | 好 |
| 文字（英文、花体字） | 人小时容易乱码（S01、S11） | 这 8 组全部正确 |
| 颜色 | S03 色差明显 | 准，S07 略偏红 |
| 关键款式（领型、袖长、版型） | S05、S12 走样 | 这 8 组都对；宽松款有时穿得稍合身 |
| 模特图"串货" | 常见（裤子、姿势、项链、手表） | 这 8 组没有出现 |
| 速度 | 免费账号要排队 1～5 分钟 | 约 1 分钟，不排队 |
| 水印 | 有 | 没有 |
| 一个新问题 | — | 人物原来有外套时，可能只换里面那件（S10、S11） |

### 下一步建议

1. **FASHN 明显更好，建议作为 M2 的首选。** 可灵 12 组只有 6 组能用，不再继续测。
2. **还不能说 FASHN 过了 9/12 的门槛**：12 组只跑了 8 组。剩下 4 组（S06、S08、S09、S12）里只要再有 1 组能用就过线。建议用 FASHN API 跑这 4 组（需要用户自己充值）。用 API 跑也能顺便确认：产品以后要接的 API 和网页版 Agent 效果是否一样。
3. **人物原来有外套时怎么换**：S10、S11 的问题要在产品里定规则，比如用户建档时要求只穿一件上衣拍照，或者让用户选"换掉外套"还是"换里面那件"。
4. **商品图预处理**仍值得做（见上面的裁剪小实验），可以让结果更稳定。

## M1 收尾（2026-10-20）

决定先不充值 API，按现有结果结束 M1：

- **选 FASHN 作为 M2 的试衣服务。** 同样 8 组，FASHN 8/8 能用，可灵 4/8（可灵 12 组一共 6/12）。
- **12 组门槛没有正式跑完**：FASHN 只跑了 8 组，S06、S08、S09、S12 没有结果，所以不能写成"12 组过了 9 组"。这 4 组的难点（拼图、宽松衬衫穿在大码身上、印花在宽身材上、修身短款）在 FASHN 跑过的组里还没覆盖到。
- **M2 开始接 FASHN API 时，先补跑这 4 组**，用同样的提示词和打分标准。如果 4 组里一组都不能用（总共 8/12），回头重新评估服务的选择。
- 产品里要定的规则：人物原来有外套时怎么换（S10、S11）；商品图要不要先自动抠出上衣（裁剪小实验）。
